# 域随机化（Domain Randomization）策略

## 核心原则

- **能测准的参数做系统辨识，不做随机化**——随机化是为代价高昂的「不确定性」买保险，不是偷懒的借口。
- **随机化范围从实测开始定**：测得摩擦 0.6±0.1，DR 就给 0.4~0.9（覆盖误差+工况变化），不要盲目 ±100%。
- **渐进式扩大（DR curriculum）**：先窄范围让策略学会任务，再逐步拉宽；一步到位 wide DR 经常训不出来。

## 参数随机化对照表

| 参数 | 建议方式 | 经验范围 | 备注 |
|---|---|---|---|
| 地面/接触摩擦系数 | DR | 实测值 ×[0.5, 1.5] | 腿足/轮式最关键参数之一 |
| 连杆质量 | DR | ±10%（有负载变化 ±30%） | 结合质心一起扰动 |
| 质心位置 | DR | 每轴 ±1~2 cm | 末端负载场景加大 |
| 动作延迟 | DR | 0~20 ms 均匀采样 | 必须覆盖真机实测最大值 |
| 控制周期抖动 | DR | ±20% 周期 | 模拟通信抖动 |
| 电机强度（力矩系数） | DR | ±10~15% | 模拟个体差与温漂 |
| 静摩擦/背隙 | DR | 辨识值 ±50% | 难测准，交给 DR 合理 |
| 观测噪声 | DR | 传感器实测噪声 ×[1, 2] | 含编码器、IMU、相机 |
| 外力扰动 | DR | 随机脉冲推力（大小按任务定） | 提升鲁棒性的高性价比手段 |
| 初始状态 | DR | 任务空间均匀采样 | 覆盖率直接影响真机成功率 |
| 关节 damping/friction | SysID 优先，残差 DR | 辨识值 ±30% | — |
| 重力/IMU 安装偏角 | SysID | — | 能测准，别随机 |

## 视觉域随机化（用 Isaac Replicator 或等效工具）

优先级从高到低：

1. **光照**：强度、方向、色温随机；这是 sim2real 差距最大来源。
2. **材质/纹理**：桌面、地面、目标物体表面随机化；可用程序化纹理 + 真实照片纹理混合。
3. **相机**：位姿小扰动（±2 cm/±2°）、焦距 ±5%、曝光/增益/噪声。
4. **背景与干扰物**：随机摆放 distractor 物体。
5. **目标物体**：颜色、尺寸（若任务允许）小范围变化。

**经验**：深度图/分割图的 sim2real 远好于 RGB。能避开 RGB 就避开；必须用 RGB 时考虑「仿真预训练 + 少量真机微调」。

## 训练技巧

- **每 episode 重采样** DR 参数，而不是固定一批环境。
- **记录每个环境的 DR 参数**，真机失败案例对照参数分布找盲区。
- **特权信息（privileged learning）**：训练时 critic/teacher 可见真实物理参数，actor/student 只看可得观测，显著提升可训性。
- **真机数据回灌（real-to-sim-to-real）**：把真机失败段回放，针对性更新仿真模型或收窄/移动 DR 分布。

## 诊断：gap 在哪一层

| 真机失败模式 | 疑似层 |
|---|---|
| 动作发出但电机跟不上 | 执行器模型/延迟 |
| 打滑、站立不稳 | 摩擦/接触模型 |
| 任务中后期才失败 | 动力学随温度/电量变化 → 扩 DR 覆盖 |
| 起始就失败 | 初始状态分布/观测不一致 |
| 仿真里也训不出来 | 不是 sim2real 问题，回去改奖励/课程/算法 |
