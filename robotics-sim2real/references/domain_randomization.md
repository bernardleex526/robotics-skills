# 域随机化（Domain Randomization）策略

## 核心原则

- **系统辨识给 nominal 与不确定度，DR 覆盖残差和真实变化**。即使参数可测，批次、温度、载荷、磨损和辨识误差仍可能需要小范围随机化。
- **随机化分布从实测开始定**：区分测量噪声、个体差异和运行变化；使用截断分布/联合分布保持质量、质心、惯量等物理一致性。
- **渐进式扩大（DR curriculum）**：先窄范围让策略学会任务，再逐步拉宽；一步到位 wide DR 经常训不出来。

## 参数随机化对照表（仅作实验起点，不是默认值）

| 参数 | 建议方式 | 经验范围 | 备注 |
|---|---|---|---|
| 地面/接触摩擦系数 | SysID + DR | 覆盖实测材料/湿度分布 | 腿足/轮式关键参数之一，接触模型通常不止一个实数 |
| 连杆质量/惯量 | 测量 + 残差 DR | CAD/称重公差与负载集合 | 质量、质心、惯量联合采样 |
| 质心位置 | 测量 + 残差 DR | 装配与负载实测包络 | 不独立破坏惯量物理一致性 |
| 动作延迟 | 测量 + DR | 覆盖实测分位数与故障门槛 | 区分固定延迟、抖动和丢帧 |
| 控制周期抖动 | 测量 + DR | 来自 trace 的经验分布 | 保持非负并考虑相关突发 |
| 电机强度（力矩系数） | SysID + DR | 个体、温度和电量实测 | 同时遵守电流/热限制 |
| 静摩擦/背隙 | SysID + 残差 DR | 正反向实验置信区间 | 可能需要迟滞模型 |
| 观测噪声 | 测量 + DR | 传感器实测频谱/异常模型 | 不只加独立高斯白噪声 |
| 外力扰动 | DR | 随机脉冲推力（大小按任务定） | 提升鲁棒性的高性价比手段 |
| 初始状态 | DR | 从物理可行且符合 reset/deployment 分布的状态采样 | 保持变量相关性；拒绝碰撞、不可达、闭链/稳定性违规状态并统计覆盖率 |
| 关节 damping/friction | SysID 优先，残差 DR | 辨识置信区间 + 工况变化 | — |
| 重力/IMU 安装偏角 | 标定 + 残差 DR | 装配公差与重装误差 | nominal 要标定，残余误差可随机化 |

## 视觉域随机化（用 Isaac Replicator 或等效工具）

优先级从高到低：

1. **光照**：按真机数据覆盖强度、方向、色温、阴影与曝光联动；其优先级由任务对这些因素的
   敏感性和部署数据消融决定，不预设为所有视觉任务的最大 gap。
2. **材质/纹理**：桌面、地面、目标物体表面随机化；可用程序化纹理 + 真实照片纹理混合。
3. **相机**：位姿、焦距、曝光/增益/噪声按标定不确定度和装配/自动曝光实测分布采样。
4. **背景与干扰物**：随机摆放 distractor 物体。
5. **目标物体**：颜色、尺寸（若任务允许）小范围变化。

模态选择取决于传感器、任务和部署可得信息。深度/分割可减少部分纹理与光照差异，但也有
仿真传感器噪声、边缘和缺失值 gap；RGB 则需要覆盖材质、曝光与背景变化。用目标数据集做对比，而非先验排名。

## 训练技巧

- **按参数语义选择事件时机**：
  - `startup / worker`：机器人身份类参数，如连杆质量、惯量和固定执行器特性；若跨 worker
    采样，要把 worker 身份记录进实验元数据。
  - `reset / episode`：初始状态、可变负载、地面材质等 episode 条件。
  - `interval / step`：外力、丢帧、短时噪声等运行事件，按有界过程触发。
  - `temporal process`：温度、电量、bias 漂移等具有时间相关性的变化；不能每步独立抽样。
- **确定性与复现**：保存全局/环境 RNG seed、采样事件、分布版本和每个环境的参数；并行环境
  顺序变化时也要验证复现边界。
- **记录每个环境的 DR 参数**，真机失败案例对照参数分布找盲区。
- **特权信息（privileged learning）**：训练时 critic/teacher 可见真实物理参数，actor/student
  只能看部署契约声明的可得观测；导出时自动检查 actor 输入，避免 privileged observation 泄漏。
- **真机数据回灌（real-to-sim-to-real）**：把真机失败段回放，针对性更新仿真模型或收窄/移动 DR 分布。

## 诊断：gap 在哪一层

| 真机失败模式 | 疑似层 |
|---|---|
| 动作发出但电机跟不上 | 执行器模型/延迟 |
| 打滑、站立不稳 | 摩擦/接触模型 |
| 任务中后期才失败 | 动力学随温度/电量变化 → 扩 DR 覆盖 |
| 起始就失败 | 初始状态分布/观测不一致 |
| 仿真里也训不出来 | 不是 sim2real 问题，回去改奖励/课程/算法 |
