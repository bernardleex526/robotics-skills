# 真机部署安全检查清单

> 强制规则：每次升级部署阶段（离线回放→硬件在环→低功率→全功率）前，逐项过本清单。任何一项 ❌ 都不允许进入下一阶段。

## A. 急停与失能链路

- [ ] 硬件急停按钮有效，拍下后 **切断动力电**（不只是发软件指令）
- [ ] 软件急停（deadman/心跳丢失自动 stop）已验证：杀掉控制进程，机器人必须进入安全态
- [ ] 通信中断（拔网线/关 WiFi）时机器人行为已实测：默认为「去使能」或「缓停」，**不是**「保持最后指令」
- [ ] 掉电恢复后不会自动上电运动（需人工重新使能）
- [ ] 急停复位后策略状态机从零开始，无残留动作缓存

## B. 限位与边界

- [ ] 软件限位（关节位置/速度/力矩）在 **控制栈最底层** 生效，不依赖策略自觉
- [ ] 机械硬限位就位且可承受最大速度撞击
- [ ] 工作空间电子围栏（臂类）/ 虚拟墙（移动底盘）已配置
- [ ] 策略输出在送入驱动器前经过独立的安全限幅层（不看策略脸色）

## C. 电气与功率

- [ ] 首次上电用限流电源或串联限流电阻，逐步放开
- [ ] 母线电压跌落（大动作时）不会导致控制器复位
- [ ] 电池低压保护阈值已设，低电量时任务自动降级/停止
- [ ] 电机与驱动器温度监控生效，超温自动去使能

## D. 部署过程控制

- [ ] 首次低功率测试：机器人吊装/架空（腿足）或放空旷围栏区（底盘/臂）
- [ ] 操作员明确「异常时谁先按急停、谁断电」分工
- [ ] 测试区无无关人员与易碎物
- [ ] 全程录 bag（所有指令+观测+策略内部状态），失败可复盘
- [ ] 每次只改一个变量（模型版本/参数/环境），失败可归因

## E. 策略/软件健康

- [ ] 当前策略版本号、训练配置、DR 参数已记录存档
- [ ] 策略推理耗时实测 < 控制周期的 50%（留出调度余量）
- [ ] 观测异常（NaN、越界、传感器掉线）有兜底：进入安全态而非继续推理
- [ ] 看门狗：控制循环心跳丢失 >100 ms 自动急停
- [ ] 回滚方案就绪：上一个稳定版本的部署包一键可恢复

## F. 验收指标（全功率常态运行前）

- [ ] 连续运行 ≥2 小时无保护性停机
- [ ] 任务成功率达到仿真评估的 90% 以上（差距过大回 Step 3 补 DR/SysID）
- [ ] 全温度范围（冷启动/热机）行为一致
- [ ] 文档：已知失败模式与人工干预点写入运维手册
