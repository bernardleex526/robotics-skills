# 真机部署安全检查清单

> 使用规则：每次扩大执行器权限、速度、负载或工作空间前逐项审查。项目风险评估可以增加更严格的
> gate；本清单不能替代安全设计、验证或认证。

## A. 急停与失能链路

- [ ] 经风险评估选择并验证停止功能（如 STO、受控停止、制动器动作或组合）；重力负载不能默认“直接切动力”就是安全
- [ ] 软件 watchdog/deadman 已验证：杀掉控制进程后进入定义明确的安全状态；它不称为安全额定急停
- [ ] 通信中断（拔网线/关 WiFi）已实测：不会无限保持最后运动指令，并按机器人风险定义执行有界停止/保持
- [ ] 掉电恢复后不会自动上电运动（需人工重新使能）
- [ ] 急停复位后按风险评估定义的安全初始化状态恢复，不自动续跑旧 goal、旧积分或残留动作缓存

## B. 限位与边界

- [ ] 软件限位（关节位置/速度/力矩）在 **控制栈最底层** 生效，不依赖策略自觉
- [ ] 机械止挡、软件限位、制动距离与缓冲装置按最大可信故障能量设计；正常测试不得用高速撞限位验收
- [ ] 工作空间电子围栏（臂类）/ 虚拟墙（移动底盘）已配置
- [ ] 策略输出在送入驱动器前经过独立的安全限幅层（不看策略脸色）

## C. 电气与功率

- [ ] 首次上电按驱动器/电源厂商的预充、限流和接触器流程执行；不使用未经电气设计验证的临时串联电阻方案
- [ ] 母线电压跌落（大动作时）不会导致控制器复位
- [ ] 电池低压保护阈值已设，低电量时任务自动降级/停止
- [ ] 电机与驱动器温度监控生效；超温进入风险评估定义的安全状态（如降额、受控停止、
      保持/抱闸、STO 的设备特定顺序），重力负载不得因机械式“去使能”而自由坠落

## D. 部署过程控制

- [ ] 首次执行器测试使用经风险评估的支撑、夹具、隔离区和输出 envelope；吊装/架空是否安全取决于机构和吊点设计
- [ ] 操作员明确「异常时谁先按急停、谁断电」分工
- [ ] 测试区无无关人员与易碎物
- [ ] 全程录 bag（所有指令+观测+策略内部状态），失败可复盘
- [ ] 每次只改一个变量（模型版本/参数/环境），失败可归因

## E. 策略/软件健康

- [ ] 当前策略版本号、训练配置、DR 参数已记录存档
- [ ] 测量推理 WCET/P99、调度与通信开销，剩余裕量满足 deadline 和故障恢复预算
- [ ] 观测异常（NaN、越界、传感器掉线）有兜底：进入安全态而非继续推理
- [ ] 看门狗超时由控制周期、最大速度、停止距离和通信抖动预算计算，并已通过故障注入验证
- [ ] 回滚方案就绪：上一个稳定版本的部署包一键可恢复

## F. 验收指标（扩大运行包络前）

- [ ] 覆盖项目规定的任务次数、持续时间和负载，无超出门槛的保护停机或异常
- [ ] 真机成功率、失败模式和置信区间满足项目门槛；不能用固定“仿真成绩的 90%”跨任务验收
- [ ] 覆盖数据表和使用场景规定的温度/电量包络，行为与保护逻辑符合验收标准
- [ ] 文档：已知失败模式与人工干预点写入运维手册

## G. 标准与适用范围

标准必须由合格人员结合设备类别、用途和法域选择。以下仅是常见入口：

- [ISO 12100:2010](https://www.iso.org/standard/51528.html)：机械风险评估与风险降低方法。
- [ISO 13849-1:2023](https://www.iso.org/standard/73481.html)：控制系统安全相关部分的设计原则。
- [IEC 62061:2021](https://webstore.iec.ch/en/publication/59927)：机械安全相关控制系统的功能安全。
- [ISO 10218-1:2025](https://www.iso.org/standard/73933.html) 与
  [ISO 10218-2:2025](https://www.iso.org/standard/73934.html)：工业机器人及机器人应用；
  服务机器人、公共空间或其他设备类别不能未经适用性分析直接套用。
- [ISO 3691-4:2023](https://www.iso.org/standard/83545.html)：无人驾驶工业车辆及其系统
  （含部分 AMR/AGV 场景）的设备类别入口。
- [ISO 13482:2014](https://www.iso.org/standard/53820.html)：个人护理机器人；是否适用仍取决于
  机器人用途、用户与工作环境。

ROS 节点、软件 stop、watchdog 和本清单通过，不等于满足上述标准的 PL/SIL 或整机合规。
