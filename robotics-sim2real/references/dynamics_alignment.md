# 模型与动力学对齐 / 系统辨识

## URDF 质量检查

按优先级排查（仿真 URDF 最常见的坑）：

1. **惯性参数**：`<inertial>` 不能是默认值。从 CAD（SolidWorks/Onshape 可导出）获取质量、质心、惯性张量；没有 CAD 就用「称重 + 摆动法/双线摆」实测。
2. **限位**：`<limit effort velocity lower upper>` 的单位和作用侧必须明确；驱动器 datasheet 是硬件上限入口，应用安全限值、热降额和控制器限值可能更低。
3. **`<dynamics damping friction>`**：初值用辨识结果，别拍脑袋。
4. **碰撞几何**：用简化凸包/基元，别用高面数视觉网格（慢且接触不稳定）。
5. **传动比**：关节侧 ≠ 电机侧，确认 URDF 描述的是哪一侧、驱动器配置一致。

## 执行器建模（RL sim2real 的关键）

真机电机不是理想力矩源。至少建三层：

```
策略动作 → [① 实测端到端延迟/抖动/丢帧/保持] → [② 驱动器环动态 τ=实测] → [③ 输出限幅+死区] → 关节力矩
```

- **辨识 τ（时间常数）**：给电机速度环/力矩环阶跃指令，录实际响应，拟合一阶惯性；残余误差大就升二阶。
- **延迟测量**：用同一时钟域对齐采样、推理、传输、驱动接收和电流/速度响应；报告端到端
  分布而非单一均值，并按需要建模 fractional delay、jitter、drop 与 zero/last-command hold。
- **非线性段**：静摩擦死区、背隙（正反转行程差）单独测，建模成死区+迟滞。

## 摩擦模型辨识

最小模型：库仑摩擦 + 粘性摩擦 `τ_f = Fc·sign(ω) + Fv·ω`。

1. 关节匀速拖动实验：不同恒定速度下测维持力矩。
2. 低速段散点拟合 Fc（截距）与 Fv（斜率）。
3. 有重力方向依赖（如臂在不同姿态）→ 说明重力项或质心错，回去改 URDF。

## 质量/质心批量辨识（臂类）

激励轨迹（傅里叶级数轨迹）+ 最小二乘回归动力学参数（barycentric 参数）。工具：MATLAB 机器人工具箱、`symoro`、`pinocchio` 的回归矩阵。带负载工作的机器人，负载参数单独辨识或加入 DR。

这属于预设激励后的离线/批量估计。若任务确需在线估计，应另行设计 RLS/EKF/优化器的可观性、
遗忘因子、投影/物理约束、异常冻结与控制稳定性边界，不能把一次最小二乘称为在线辨识。

## URDF / SDF 与转换边界

- URDF 偏机器人运动链；SDF 还能表达 world、嵌套 model、surface/contact、sensor 与 simulator
  plugin。选定唯一 source of truth，并记录 URDF→SDF/USD/MJCF 的工具和版本。
- 转换后逐项比较 frame/pose、fixed-joint lumping、质量/质心/惯量、joint axis/limit/mimic、
  transmission/actuator、collision/contact material、sensor rate/noise/topic 和 plugin 参数。
- 用静态结构检查加动态基准（自由落体、摆、匀速/阶跃、接触/摩擦）验收；不能用“文件能加载”
  证明模型等价。

## 传感器模型对齐

| 传感器 | 仿真要建模的项 |
|---|---|
| 编码器 | 量化分辨率、噪声、读数延迟 |
| IMU | 噪声密度、随机游走（用 allan 实测值）、安装偏角 |
| 力/力矩传感器 | 零漂、带宽（一阶低通）、串扰 |
| 相机 | 内参、畸变、曝光延迟、motion blur 近似 |
| 深度/激光 | 噪声随距离增长、边缘 fly-points、最小/最大量程截断 |

## 对齐验证（离线回放法）

1. 预先拆分互不重叠的 estimation 与 validation 工况，覆盖任务需要的姿态、速度、负载、温度
   和接触模式；不得在同一段数据上拟合后自证正确。
2. 用 estimation 数据拟合参数并报告置信区间、相关性/可辨识性和约束命中情况。
3. 把 validation 的同样输入送进仿真，对比输出；开环重放与闭环回放语义要分开说明。
4. 预先定义比较窗口、滤波、时间对齐和归一化分母，报告 RMSE/NRMSE、相位误差、残差白化/
   偏置及其随工况变化；门槛来自任务敏感性与独立数据，失败时保留残差供 DR 建模。

## 常见不对称点速查

| 仿真默认 | 真机现实 |
|---|---|
| 瞬时响应 | 驱动器有环带宽与延迟 |
| 力矩无上限或上限虚高 | 电流环限幅、母线电压跌落 |
| 编码器连续精确 | 量化噪声、偶尔丢线 |
| 通信零延迟零丢包 | CAN/串口抖动、偶发丢帧 |
| 接触面理想 | 地面不平、足端磨损、地面材质变化 |
