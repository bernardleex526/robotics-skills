# Robotics Skills Quality Release Implementation Plan

Date: 2026-07-29

## Acceptance Criteria

- All six skill directories validate against the portable Agent Skills layout.
- Every repository-local reference resolves.
- All confirmed user-reported defects have regression coverage and are fixed.
- Newly identified P0/P1 correctness and safety defects are fixed.
- ROS 2 Humble is the explicit baseline; known distribution differences are
  labeled.
- Runtime diagnostics terminate under frozen simulated time and handle invalid
  TF graphs without crashing.
- README, LICENSE, dependencies, coverage boundaries, and client installation
  instructions agree with the repository contents.
- The full local verification suite and CI workflow pass.

## Verification Commands

```bash
python3 -m unittest discover -s tests -v
python3 tools/check_repository.py
python3 tools/check_doc_params.py
python3 -m compileall -q robotics-ros2-infra/scripts tools tests
git diff --check
```

ROS graph and hardware checks remain documented manual acceptance steps because
they cannot be proven in a repository-only environment.
