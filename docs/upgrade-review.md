## 证据分级与限制

- 源页面核验记录在 source-audit.json：仅代表可达性/选定页面标记，不代表每个参考观点已逐句审计，也不证明链接未来有效。
- 代码单元测试、结构检查和安装复制测试证明相应离线行为，不证明模型自动触发质量。
- 真实 API smoke 只证明所记录时间/环境/查询下请求成功，不保证地区网络、配额或服务 SLA。
- 尚未在每个目标客户端中开展模型行为实测；适配路径核验与原生发现验证不同。
- 未运行 ROS、GPU、真实 bag 数据、VLN benchmark、真机闭环或功能安全验收。
- 用户未提供私有工程案例；本次补充的是可复用工程方法，不冒充个人经验。案例模板留作后续采集。

具体自动验证结果写入 verification-results.json。路由验收集为 tests/routing_cases.json，状态仍是待客户端执行。
