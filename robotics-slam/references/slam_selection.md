# SLAM 方案选型参考

## 对比总表

| 方案 | 传感器 | 维度 | 算力需求 | ROS 2 支持 | 适用场景 |
|---|---|---|---|---|---|
| slam_toolbox | 2D 激光 | 2D | 低（树莓派可跑） | 原生 | 室内服务机器人、AGV |
| Cartographer | 2D/3D 激光(+IMU) | 2D/3D | 中 | 社区移植 | 大室内、需要子图优化 |
| LIO-SAM | 多线激光+IMU(+GPS) | 3D | 高（i7 起步） | 原生 | 室外、无人驾驶、巡检 |
| FAST-LIO2 | 多线激光+IMU | 3D | 中高（更省算力） | 原生 | 算力受限的 3D 场景 |
| ORB-SLAM3 | 单/双/RGB-D/鱼眼+IMU | 3D | 中 | 社区包 | 视觉特征丰富的室内外 |
| RTAB-Map | RGB-D(+激光) | 3D 稠密 | 中高 | 原生 | 需要稠密点云/语义地图 |

## 选型决策问题

按顺序回答，快速收敛：

1. **环境是平面为主的室内？** → 2D 激光方案（slam_toolbox）。2D 方案成熟、算力低，不要为用不上的 3D 付出复杂度。
2. **有大坡度、室外、非结构地形？** → 3D LIO（LIO-SAM / FAST-LIO2）。纯激光在走廊等退化场景会漂，IMU 必须紧耦合。
3. **没有激光雷达？** → 视觉方案：纹理好用 ORB-SLAM3；要稠密地图用 RTAB-Map。视觉方案对光照/动态物体敏感，室外慎选单目（尺度漂移）。
4. **算力预算？** 嵌入式（Jetson Nano 级）→ slam_toolbox 或 FAST-LIO2；Jetson Orin/x86 → 任选。
5. **需要 lifelong 定位（地图复用）？** → slam_toolbox（序列化 posegraph）或 RTAB-Map；LIO-SAM 主要做建图，定位需另配方案（如 hdl_localization）。

## 传感器最低配置建议

- **2D 激光**：RPLidar A2/A3 级别起步；扫描频率 ≥10 Hz；量程覆盖场景对角线 1.5 倍以上。
- **3D 激光**：Velodyne VLP-16 / Livox Mid-360 / Ouster OS0 起步；Livox 注意非重复扫描要配专用驱动参数。
- **IMU**：消费级 BMI088/ICM42688 可起步；LIO 紧耦合建议噪声密度 <0.01 m/s²/√Hz 的工业级 IMU。
- **轮速计**：任何方案都建议接入，作为退化场景的兜底约束。

## 环境适配速查

| 环境特征 | 风险 | 对策 |
|---|---|---|
| 长廊/隧道 | 激光沿走廊方向退化 | LIO 紧耦合 + 轮速计；或加反光柱 |
| 玻璃幕墙多 | 激光穿透/镜面反射产生鬼影 | 换 905 nm 之外的雷达无效，改用多传感器融合，地图后处理 |
| 人流密集 | 动态点污染地图 | 开动态点滤除（slam_toolbox 无内置，需前置过滤） |
| 弱纹理白墙走廊 | 视觉特征不足 | 换激光方案或视觉-惯性紧耦合 |
| 大范围户外 | GPS 可用 | LIO-SAM + GPS 因子，或建图后转栅格供 2D 定位 |
