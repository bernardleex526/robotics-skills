# 传感器标定参考

## 0. 时间同步（最先做）

时钟域、采集时刻和驱动 stamp 不一致是 SLAM 漂移中常见且隐蔽的一类输入问题，应在调算法参数前
先量测排除；它不是所有漂移场景的固定第一根因。

- **优先使用设备支持的共同时间基准/触发**：相机外触发、激光雷达 PTP/PPS、IMU sync
  input/output 等能力和时间戳语义随硬件而异，必须按数据表与驱动验证。收到 PPS 不自动等于
  每个样本的采集时刻已与其他传感器对齐。
- **软件配对不等于同步**：Approximate/Exact TimeSynchronizer 只按消息已有 stamp 配对，不能让两个时钟变一致，也不能修正驱动写错的 stamp。
- **软同步校验**：在风险可控的激励下比较角速度/图像运动/点云运动；拖影还可能来自外参、deskew、扫描周期模型或姿态估计，不能单独归因于时间偏差。
- **测量时间偏差**：kalibr 可估计相机-IMU 时间偏移；LIO 中可评估 LI-Init 类时空估计，
  但两者上游都是 ROS 1 流程，ROS 2 使用边界见下方兼容表，估计结果仍须独立验证。
- **验收**：估计偏移、抖动和漂移，并用目标平台的最大角速度/加速度换算成允许的位姿误差。5 ms 可作为某些 LIO 的告警起点，不是跨硬件的保证线。

## 1. IMU 内参

工具：`imu_utils` / `allan_variance_ros` 可从静止数据估计 Allan 偏差相关的噪声项。

1. 按目标稳定度和估计频段选择静置采样时长，同时记录采样率、温度与量程；“固定两小时”不是所有 IMU 的充分条件。
2. 从 Allan 曲线估计白噪声与 bias instability/random walk，并保存拟合区间。
3. 用多姿态静态法、转台或厂家流程另行估计零偏、尺度因子和轴不正交；Allan 工具本身不完成这些几何标定。
4. 将噪声模型映射到具体算法的参数定义和单位；不要把 LIO-SAM 与 FAST-LIO 的参数名直接互换。

## 2. 相机内参

```bash
ros2 run camera_calibration cameracalibrator --size 8x6 --square 0.108 \
  image:=/camera/image_raw camera:=/camera
```

- 用不同距离、倾角和画面位置覆盖完整有效视场，尤其是边缘；样本数由覆盖度、参数可观性和
  独立验证残差决定，不把固定画面比例或张数当作通用通过线。命令中的 board size/square
  必须替换成实际内角点数量与测量尺寸。
- 验收：同时查看训练集与独立验证图像的重投影残差分布、边缘区域残差和参数可观性；阈值由分辨率、镜头与任务精度决定。
- 注意曝光固定、关闭自动对焦。

## 3. 外参

| 组合 | 工具 | 上游运行栈/传感器边界 | 要点 |
|---|---|---|---|
| 相机-IMU | kalibr | 上游是 ROS 1 catkin；ROS 2 常用隔离 Docker/离线 bag 转换或经过验证的 port | Aprilgrid 板，激励要充分，结果看重投影误差与估计置信度 |
| 激光-IMU | LI-Calib | 上游仅报告 ROS Kinetic/Melodic 且只支持 VLP-16，不能直接泛化到 Livox | 充分六自由度激励，避免匀速直线段占比过高 |
| 激光-IMU | LI-Init | 上游支持 Avia/Mid-360 等 Livox 输入并估计时空外参，但仍是 ROS 1 catkin/livox_ros_driver v1 | ROS 2 使用经过验证的 ROS 2 port，或隔离 ROS 1/离线转换流程 |
| 激光-相机 | direct_visual_lidar_calibration | 上游明确提供 ROS 1/ROS 2 路径；仍需锁定目标版本 | 无需标定板，靠场景强度-纹理对应 |
| 激光-底盘 | 测量 + 可观测运动/靶标优化 | 自建流程必须记录坐标、时间和真值契约 | 六自由度误差敏感性由布局、运动和任务决定；不要默认只有 z/yaw 重要 |

外参验收应使用与标定数据独立的运动/场景，比较点到平面残差、重投影残差或轨迹一致性。
双层墙只是证据之一，也可能来自时间偏移、deskew 失败、里程计误差、动态物体或回环错误。

## 4. 轮速计标定

1. **轮径**：选择足以压低人工测距相对误差、且不会打滑的直线距离，双向重复；对比轮速计与独立测量后修正 `wheel_radius`。
2. **轮距**：在不打滑的场地按任务精度选择足够角度，顺/逆时针双向重复；用独立航向真值
   （Motion Capture、经验证的扫描匹配或其他基准）拟合 `wheel_separation`，并报告方向不对称
   与重复性。固定单向圈数不是通用验收。
3. 差速底盘 odometry 协方差要合理设置（Nav2/robot_localization 融合时权重依据），别用默认值 1e-3 无脑信。

## 5. 标定结果固化

- 外参写入 URDF/xacro（用静态 TF 发布），不要散落在 launch 里手写 `static_transform_publisher` 数字。
- 时间偏移、IMU 噪声参数写入 SLAM 配置文件并加注释标注标定日期。
- 传感器拆装、碰撞或支架受力后必须重新验证外参；超出项目容差时重标。

## 6. 覆盖边界

相机-机械臂的 eye-in-hand / eye-to-hand 手眼标定涉及机器人基座、法兰、工具与标定板的
专门坐标链和 AX=XB/联合优化流程，本技能当前不提供完整工作流；不要把“相机-IMU 标定”误用为手眼标定。
